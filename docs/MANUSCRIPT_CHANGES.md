## 2. Section 2 – system model (electrical corrections)

**2.1 Power balance, Eq. 1–2 [REPLACE].** No infinite bus. For every energised bus *i* of island 𝓘:

```latex
\sum_{k\in\mathcal{G}_i} P_{k} - x_i\,P^{\mathrm{L}}_i\,(1+\kappa_i(t)) = V_i\sum_{j} V_j\,(G_{ij}\cos\theta_{ij}+B_{ij}\sin\theta_{ij}),\qquad
\sum_{k\in\mathcal{G}_i} Q_{k} - x_i\,Q^{\mathrm{L}}_i\,(1+\kappa_i(t)) = V_i\sum_{j} V_j\,(G_{ij}\sin\theta_{ij}-B_{ij}\cos\theta_{ij})
```

with the GFM primary controllers closing the system (these *are* Eq. 9–10, now inside the solver):

```latex
P_k = \mathrm{sat}_{[\underline P_k,\overline P_k]}\!\Big(P^{\mathrm{ref}}_k-\tfrac{S_k}{m_p}\,\Delta\omega_{\mathcal I}\Big),\qquad
Q_k = \mathrm{sat}_{\pm\overline Q_k}\!\Big(Q^{\mathrm{ref}}_k+\tfrac{S_k}{n_q}\,(V^0_k-V_k)\Big),\qquad
\overline Q_k=\sqrt{(I^{\max}V_kS_k)^2-P_k^2}
```

Unknowns: θ (one reference per island), all |V|, and one Δω per island; 2N equations. State this as
"droop-based power flow of an islanded inverter-formed network"; cite an islanded-microgrid
power-flow reference (e.g. Mumtaz et al., IEEE TSTE 2016). `m_p` = 3 %, `n_q` = 4 % (L221) unchanged.

**2.2 Load model, Eq. 6 [REPLACE].** `x_i ∈ [0,1]`, non-decreasing; with the governor a feeder is
energised in blocks, each block ≤ ΔP^adm (2.4), one block every `block_interval_s`; binary pick-up
(`load.pickup: binary`) remains available. Cold-load pick-up **[NEW]**:
`κ_i(t) = (k_CL − 1)·exp(−(t − t_i)/τ_CL)` per picked-up block.

**2.3 Storage, Eq. 7 [REPLACE]** with Δt and efficiencies explicit:
`SoC_{t+1} = SoC_t − Δt/E · (P⁺/η_d − η_c P⁻)`; power limit `P̄ = E / duration`; zones of L203 are
used as: normal – no penalty, critical – penalty 0.5, pre-stop – penalty 1 and only
charging/discharging allowed. Table 2 must list MW **and** MWh.

**2.4 Frequency dynamics, Eq. 11 [REPLACE] + [NEW].** Per island, on the MVA base of the online
units that still have headroom, `S_eff`:

```latex
2H\,\Delta\dot f = -\Delta p - D\,\Delta f - y,\qquad T_f\,\dot y = \Delta f/m_p - y
\;\Rightarrow\; \mathrm{RoCoF}(0^+)=\frac{\Delta P\,f_0}{2H\,S_{\mathrm{eff}}},\quad
\Delta f_\infty=\frac{-\Delta P\,f_0}{(D+1/m_p)\,S_{\mathrm{eff}}},\quad \Delta f_{\mathrm{nadir}}=1.058\,\Delta f_\infty
```

(the 1.058 follows from H = 3.5 s, D = 1, m_p = 3 %, T_f = 0.1 s). Admissible block:
`ΔP^adm = S_eff · min(2H·RoCoF^max/f0 , (Δf^max − |Δf_pre|)/(|nadir_unit| f0))`. v1's "H_sys + H_gfm"
(7.5/7.0/6.5 s on the system-load base) **[DELETE]** – there is no residual synchronous inertia in an
IBR-only island.

**2.5 Converter current limit, Eq. 12 [REPLACE]** by the capability circle above: continuous
1.0 pu (steady state), 1.2 pu short-time (transformer inrush rule). **[DELETE]** "voltage-controlled
oscillator" → "virtual oscillator control (VOC)".

**2.6 Energisation physics [NEW] (one paragraph each, all in `blackstart_env._switch_ok`).**
line charging `Q_c = Σ b V²` must fit 90 % of the island's remaining var-absorption capability;
Ferranti factor `1 + ½ (Σx)(Σb)` and off-nominal tap on the open end; transformer hard energisation
only if `S_T · k_inrush ≤ I^max · S_online` once load is connected (soft energisation before);
sync-check relay (Δf, ΔV, Δθ) for loop closing and island merging; spinning-reserve rule
`Σ P̄_k ≥ γ̂_min · demand`; under-frequency load shedding when the renewables drop; protection bands
(V, f, RoCoF) whose violation collapses the island. **[DELETE]** L229–230 (protection statement was
backwards) and "radial constraint" on the meshed 14/39-bus systems.
